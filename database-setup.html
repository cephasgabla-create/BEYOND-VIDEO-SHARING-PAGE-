Beyond Database Setup

This page explains how to connect Beyond to its Supabase backend.

  1. Create or open the Supabase project configured in supabase.js.
  2. Open the Supabase SQL Editor.
  3. Review and run the canonical Beyond Supabase setup SQL. It creates the baseline profiles, videos, follows, likes, comments, storage bucket and policies, and the profile-creation RPC. Review any SQL errors before testing.
  4. Confirm the Supabase Project URL and public publishable/anon key in supabase.js point to that same project. Never put a database password or service-role/secret key in browser code.
  5. Enable Google and any other social providers separately in Supabase Authentication settings. Configure the OAuth callback and allowed redirect URLs as described in the Google OAuth guide.

Important: This SQL file is the baseline, not a guarantee that every optional Creator Studio, messaging, live-streaming, notification, blocking, or analytics feature is installed. Those features need their own matching tables, policies and RPCs before they can work against a live database.
