Beyond Database Setup

This page explains how to connect Beyond to its persistent database.

  1. Create a Supabase project.
  2. Open the SQL Editor and run supabase-schema.sql.
  3. Copy the Project URL and anon key into supabase.js.
  4. Load the Supabase browser library before supabase.js.

The database is designed for profiles, videos, posts, comments, follows, likes, messages, live rooms, live chat, and reactions.
