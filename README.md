# Beyond - Video Sharing Page

Beyond is a TikTok-style short-video web app prototype.

## Pages
- Home video feed
- Login
- Sign up
- Upload
- Profile
- Search

## Run locally
Open index.html with VS Code Live Server.

## Note
This version stores videos and comments in the browser with IndexedDB. It is a prototype; production accounts, cloud video storage, and a backend are still needed.
